================================================================================
                        🔧 KEY FIXES APPLIED
================================================================================

1. BuildScript.cs Scene Name
   Problem: Hardcoded "GameScene.unity"
   Solution: Read from EditorBuildSettings (dynamic scene names)

2. SimpleGameManager Script
   Problem: Script referenced but never created
   Solution: Created script with correct GUID in shared project

3. Shared Project Structure
   Problem: /opt/unity-mcp/shared-project didn't exist
   Solution: setup-shared-project.py creates complete structure

4. Scene Name Tracking
   Problem: Build pipeline didn't track scene names
   Solution: create_project() returns (path, scene_name) tuple

5. BuildScript Exit Codes
   Problem: Unity might hang after build
   Solution: Added EditorApplication.Exit(0) on success

================================================================================
                        🆘 TROUBLESHOOTING
================================================================================

If build fails:
  • Check: journalctl -u unity-mcp -n 100
  • Check: tail -200 /tmp/unity_build_*.log
  • Verify: ls -la /opt/unity-mcp/shared-project/

If game won't load:
  • Check: ls -la /var/www/html/games/{build_id}/
  • Check browser console for JavaScript errors
  • Verify index.html exists in build directory

Rollback if needed:
  • Backups created in: /opt/unity-mcp/backup/YYYYMMDD_HHMMSS/
  • Copy files back and: systemctl restart unity-mcp
